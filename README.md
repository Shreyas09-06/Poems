# Somewhere Between the Lines

A responsive, searchable poetry archive built from the supplied Word document.

## Contents
- `index.html` — the poetry archive website, containing 83 sections in the document's reading order.
- Images from the Word document are not included.

## View locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will show the published URL when deployment is ready.
